# plantvillage

Official source: https://huggingface.co/datasets/mohanty/PlantVillage

Downloads the original data.zip archive published by the Hugging Face repository. The repository's current dataset loader exposes only a path manifest, so the downloader preserves the source archive rather than reconstructing images from the loader. The source is commonly reported as 54,306 images, 14 crop species and 38 classes. Hugging Face lists CC BY-SA 3.0; review share-alike obligations before redistribution or product use.

Downloaded by CropScope AI shared dataset downloader. Original source files are not modified.
